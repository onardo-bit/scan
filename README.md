# GiftScope — сканер рынка NFT-подарков Telegram

Telegram-бот + веб-консоль для мониторинга флоров (минимальных цен) NFT-подарков:
каталог, поиск, мониторинг цен с алертами, избранное, история изменений,
мультипользовательский режим и админ-панель. Полностью на русском.

## Функции бота

- **NFT-флоры** — каталог коллекций с актуальными ценами, офферами, сортировкой и страницами
- **Поиск подарка** — нечёткий поиск по названию
- **Мониторинг цен** — отслеживание выбранных подарков, алерты без дублей
- **Избранное** — быстрый доступ к сохранённым коллекциям
- **История изменений** — каждое движение флора: было/стало/Δ/%
- **Настройки** — алерты вкл/выкл, порог чувствительности (%)
- **/admin** — статистика, состояние источника, управление интервалом (только владелец)

## Источники данных

Цепочка провайдеров с автоматическим fallback (заменяемый модуль `src/lib/market/providers.ts`):

1. **Tonnel Marketplace** — публичный API `pageGifts` (основной)
2. **Portals Marketplace** — при наличии `PORTALS_AUTH_DATA`
3. **Встроенный demo-фид** — движок продолжает работать даже без доступа к биржам

## Запуск

### Локально / домашний ПК (long polling, без домена)

```bash
npm ci
# создайте .env:
#   DATABASE_URL=postgresql://user:pass@host:5432/db
#   TELEGRAM_BOT_TOKEN=токен_от_@BotFather
#   TELEGRAM_POLLING=true
#   ADMIN_CHAT_ID=ваш_telegram_id
npm run build
npm start          # сам создаст таблицы (drizzle-kit push)
```
